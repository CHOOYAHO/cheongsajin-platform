## 1~5회기 최신 운영안

2026-09-07 기준 최신 확정안이다. 기존 코드, 문서, 페이지 내용과 아래 운영안이 충돌하면 아래 운영안을 우선한다. 광시중학교와 예산고등학교 모두 동일한 1~5회기 구조로 운영한다. 이미 제작·인쇄된 활동책자는 수정 대상이 아니며, 웹 기능과 실제 운영을 아래 구성에 맞춘다.

### 1회기: 첫 만남 및 진로·직업 이해

- 목표: 프로그램과 멘토를 이해하고 청소년-멘토 간 관계를 형성한다. 진로와 직업에 대한 기본 개념을 이해한다.
- 주요 활동: 청·사·진 프로그램 소개 및 오리엔테이션, 안전교육 및 운영 안내, 멘토 소개, 청소년-멘토 관계형성 활동, 진로와 직업의 개념 알아보기, 멘토의 실제 진로·대학생활 경험 공유.
- 핵심 흐름: 프로그램 이해 → 관계형성 → 진로·직업에 대한 기본 이해.

### 2회기: 선호·강점 탐색

- 목표: 자신의 흥미와 선호를 탐색하고, 직업마다 중요하게 요구되는 역량이 다를 수 있음을 이해한다.
- 자기이해검사: 자신의 흥미와 진로 특성을 탐색한다.
- `좋아! 싫어!`: 여러 활동·상황에 대해 좋아 / 그저 그래 / 싫어로 응답한다. 개인 결과와 모둠별 워드클라우드로 선호와 비선호를 탐색하고, 단순 선택보다 왜 좋아하는지 / 왜 싫어하는지를 생각한다.
- `강점 경매장`: 모둠별로 하나의 직업을 선정하고, 해당 직업에 중요하다고 생각하는 역량을 가상화폐로 경매해 획득한다. 경매 종료 후 실제 직업정보와 비교하면서 직업과 역량의 관계를 탐색한다.
- 주의: 강점 경매장은 청소년 개인의 실제 강점을 판정하는 활동이 아니다. 특정 직업에는 어떤 역량이 필요하며 왜 필요한가를 탐색하는 활동이다.
- 핵심 흐름: 나의 흥미·선호 탐색 → 다양한 역량 이해 → 직업과 역량의 관계 탐색.

### 3회기: 진로 역량 갖추기

- 목표: 2회기에서 발견한 선호와 역량을 관심 직업과 연결한다. 관심 직업이 실제로 수행하는 업무를 구체적으로 이해한다. 희망 직업에 실제 지원했다고 가정한 AI 채용면접을 경험한다.
- 주요 활동: 2회기 결과 돌아보기, 내 경험 속 역량 찾기, 관심 직업 연결하기, `이 직업, 무슨 일을 할까?` 업무 브레인스토밍, 실제 업무 들여다보기, AI 가상면접.
- 업무 브레인스토밍: 자체 청·사·진 홈페이지를 활용한다. 선택한 직업이 실제로 어떤 일을 할지 청소년들이 먼저 자유롭게 예상하고, 다른 청소년들의 생각도 함께 확인한다.
- 실제 업무 들여다보기: 브레인스토밍 결과와 실제 직업정보를 비교하며 알고 있었던 업무 / 새롭게 알게 된 업무 / 다르게 알고 있었던 내용을 확인하고, 실제 업무와 필요한 역량을 연결한다.
- AI 가상면접: 단순 직업정보 Q&A, 직업인 역할극, 업무상황 체험이 아니다. 청소년이 자신이 선택한 희망 직업에 실제 지원했다고 가정하고 진행하는 채용면접이다. AI가 면접관, 청소년이 지원자 역할을 맡고, 지원 직업에 맞는 질문과 답변에 따른 후속 질문을 이어간다. 면접 종료 후 자신의 답변과 해당 직업에 필요한 역량을 돌아볼 수 있어야 한다.
- 핵심 흐름: 나의 선호·역량 → 관심 직업 → 실제 업무 → 필요한 역량 → AI 채용면접.

### 4회기: 직업 탐색

- 목표: 다양한 관점에서 진로와 직업을 탐색하고 자신의 진로에 대한 생각을 확장한다.
- 운영 방향: 전문강사(퍼실리테이터) 연계 프로그램으로 운영한다. 강사의 전문영역과 실제 운영 가능한 프로그램을 협의하여 세부 활동을 확정한다. 따라서 현재 웹페이지에서 특정 세부 활동을 임의로 확정하거나 만들어내지 않는다.
- 주요 방향: 전문강사와 함께하는 참여형 진로·직업 탐색, 청소년 간 의견 공유 및 상호작용, 다양한 진로·직업에 대한 관점 확장, 활동을 통해 새롭게 알게 된 내용과 관심 분야 기록, 5회기 미래설계로 이어질 개인별 발견 정리.
- 핵심 흐름: 다양한 진로·직업 탐색 → 생각 확장 → 나에게 다시 연결.

### 5회기: 나만의 청사진

- 목표: 1~4회기에서 발견한 내용을 종합하여 자신의 미래 모습을 구체화한다. 자신의 진로 탐색 결과를 하나의 미래 포트폴리오로 만든다.
- 주요 활동: 지금까지의 활동 돌아보기, 10년 뒤의 나 상상하기, Notion 미래 포트폴리오 제작, 미래 명함 등 미래 모습을 표현하는 결과물 제작, 프로그램 전체 활동 및 변화 돌아보기.
- Notion 미래 포트폴리오: 활동책자와 홈페이지에 축적한 내용을 활용해 개인별 Notion 포트폴리오를 만든다. 기존 기록을 단순 복사하지 않고 중요한 내용을 선택하여 자신의 언어로 재구성한다.
- 핵심 흐름: 1~4회기 기록 종합 → 미래의 나 구체화 → Notion 포트폴리오 → 나만의 청사진 완성.

### 개발 시 특히 확인할 사항

- 홈페이지의 기존 회기별 설명이 최신 운영안과 다르면 최신 운영안에 맞게 수정한다.
- 3회기 AI 가상면접은 반드시 희망 직업에 지원하는 실제 채용면접 시뮬레이션으로 이해한다.
- AI 가상면접을 단순 직업정보 Q&A, 직업인 역할극, 업무상황 체험 기능으로 구현하지 않는다.
- 3회기에는 업무 브레인스토밍 및 실제 직업정보 비교 활동이 포함된다.
- 4회기 세부 프로그램은 전문강사와 협의 후 확정 예정이므로 임의로 세부 콘텐츠를 확정하지 않는다.
- 5회기의 핵심 결과물은 Notion을 활용한 개인별 미래 포트폴리오다.
- 기존 디자인, 인증/권한 구조, Firebase 데이터 구조 등에 영향을 주는 수정은 현재 저장소 구조를 먼저 확인한 뒤 최소 변경으로 진행한다.

## 현재 구현된 기능

- 인터넷에서 접속 가능한 반응형 랜딩 페이지
- 로그인 화면 상단의 작은 `접속 QR` 버튼과 QR 이미지 팝업(바깥 영역·닫기 버튼·ESC로 닫기)

- 학생은 임시 목록 확인 후 Firebase 익명 인증, 멘토/관리자는 서버 PIN 검증 후 12시간 권한 세션 생성

- 메인 안내 카드 4종의 세부 페이지(청사진 안내, 역할별 프로필 작성, 멘토 소개, 예산군청소년수련관 소개)
- 예산군청소년수련관 소개 페이지에 공식 소개·주요 활동·운영시간·문의처와 홈페이지/프로그램 접수 링크를 반영함
- 학교 선택 로그인은 학생 프로필, 멘토/관리자 선택 로그인은 멘토 프로필 작성 화면을 제공함
- 멘토/관리자가 저장한 소개는 Firestore `mentorProfiles`에 계정별로 저장되고 멘토 소개 화면에 실시간 표시됨
- 멘토 프로필 항목은 한 줄 소개, 학교/학과, 관심 분야, 전공 선택 이유, 관심 진로·직업, 대학생활, 강점, 청소년에게 전할 말의 8개로 구성함
- 멘토/관리자 로그인은 1회기를 완료 상태로 보고 2회기 활동을 바로 열어 둠
- 회기별 카드와 진행률 UI
- 2회기의 네 가지 세부 활동 페이지 틀
- 3·4·5회기 활동 세부 안내 페이지를 최신 운영안 기준으로 갱신함. 3회기는 업무 브레인스토밍·실제 업무 비교·AI 채용면접, 4회기는 전문강사 연계 직업 탐색 운영 방향, 5회기는 Notion 미래 포트폴리오 중심으로 정리함
- `좋아, 싫어!` 선호 탐색 미니게임(6개 영역, 24문항을 한 문항씩 표시, 시작 전 규칙 안내, 문항당 5/7/10초 선택, 부드러운 연속 타이머 바, 3초 이하 빨간 경고, 일시정지/재개, 좋아/그저 그래/싫어 선택, 시간 초과 시 고민돼요 자동 기록, 개인 선택 요약, 다시 하기, 계정당 하나의 Firestore 결과 제출·덮어쓰기)
- `강점 경매장` 다중기기 동기화 코드(방 만들기/입장, 방장 설정, 참가자 대기실, 30초 참가자별 직업 선택, 시작 전 5초 카운트다운, 제한시간 경매, 막판 입찰 5초 연장, 낙찰, 잔액·NORMAL/RARE/EPIC 강화, EPIC 입찰 차단). 직업 선택 저장·입찰 검증·낙찰 판정은 Cloud Functions 트랜잭션으로 처리함
- `강점 경매장` 로비에서 혼자 실행할 수 있는 방장용·참여자용 테스트 게임. 가상 참가자가 자동 투표·입찰하며 6개 상품으로 전체 흐름을 연습하고, 테스트 데이터는 Firebase에 저장하지 않음
- 강점 경매장 데이터는 `직업별 중요도(핵심 4/관련 4/우선도 낮음 3)`, `실제 출품 덱`, `참가자 보유 등급`을 서로 분리함. 게임 중 중요도는 숨기고 종료 후 비교·토론 화면에서 공개함
- 공통 하단 협력기관 영역
  - 충청남도
  - 충청남도교육청
  - 충남사회서비스원
  - 예산군청소년수련관
- PC 및 모바일 반응형 배치

- 실제 참여자 명단 등록
- 회기별 활동지 입력과 Firestore 저장
- 임시저장 및 제출 기능
- 멘토 피드백 작성과 학생별 열람

- 학생별 진행률 계산
- 결과물 및 포트폴리오 생성
- `좋아, 싫어!` 핵심 항목 최대 3개 재선택, 자유입력, 전체 워드클라우드, 지도자용 결과 화면
- `강점 경매장` QR 입장은 아직 구현하지 않음
- 파일 업로드용 Firebase Storage 운영 연결

학생 로그인은 코드 안의 임시 허용 목록으로 검사하며 예산고등학교와 광시중학교 모두 이름 `1`, PIN `1`만 통과한다. 멘토/교사/관리자는 발급된 이름과 6자리 PIN을 Firebase 서버 함수로 검증한다.

## 주요 파일

- `src/App.tsx`: 랜딩 페이지, 로그인 흐름, 예시 학생 활동실, 협력기관 푸터
- `src/App.css`: 전체 화면과 모바일 스타일
- `src/lib/firebase.ts`: 환경변수 기반 Firebase 초기화
- `src/types/domain.ts`: 초기 도메인 타입
- `src/data/auction.ts`: 30개 공통 역량 사전, 직업별 11개 역량 중요도, 경매 덱 생성 함수
- `firestore.rules`: Firestore 보안 규칙
- `storage.rules`: Storage 보안 규칙 초안
- `.github/workflows/deploy-pages.yml`: GitHub Pages 자동 배포
- `.env.example`: 필요한 Firebase 환경변수 이름

## 현재 화면 관련 결정사항

- 랜딩 페이지 H1: `청·사·진 - 청소년의 사기진작 진로멘토링`
- 랜딩 페이지 H2: `내 가능성을 발견하고, 미래의 청사진을 그려요.`
- 예전에 있던 아이콘형 `청·사·진` 제목과 파란 소제목은 제거함
- `선호·강점 → 진로역량 → AI 면접 → 청사진` 표시는 제거함
- 협력기관 로고는 모든 화면 하단에 표시함
- 충남사회서비스원 로고 원본에는 큰 흰 여백이 있어 CSS로 확대·위치 보정 중임
- 로고 크기 및 위치는 현재 사용자 확인을 받은 상태

## 권장 다음 작업

가장 먼저 참가코드/PIN 인증 설계를 확정하는 것이 좋다.

권장 흐름:

1. 관리자가 참여자별 참가코드와 PIN을 발급한다.
2. PIN 원문은 Firestore에 저장하지 않고 안전한 검증 방식을 사용한다.
3. 검증 성공 시 Firebase 사용자와 참여자 레코드를 연결한다.
4. 학생·멘토·관리자 권한을 분리한다.
5. 테스트 계정으로 Firestore 규칙을 검증한다.

청소년 개인정보가 포함되므로 실제 명단을 넣기 전에 데이터 항목, 보관 기간, 접근 권한을 사용자와 먼저 확정해야 한다.
